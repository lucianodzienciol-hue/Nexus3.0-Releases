Los instaladores pesan ~131 MB y GitHub no permite archivos de más de 100 MB
dentro del repositorio, así que los binarios viven como assets del release
[`demos`](https://github.com/lucianodzienciol-hue/Nexus3.0-Releases/releases/tag/demos).

Ese release está marcado como **prerelease** a propósito: así no se convierte en
`/releases/latest`, que es lo que consulta el actualizador automático de la app.

`demos.json` tiene la versión, el tamaño y el sha256 de cada demo.
